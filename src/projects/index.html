Amateur Radio Software Development

  • Claus' Morse Trainer Android app to learn morse code by listening.
  • IcomClockOmniRig Windows executable to set the Icom IC-7300 clock via OmniRig.
  • IC-7300-time-sync Python script to sync the radio's clock with your computer via CAT commands.
  • QRZ Auto Login extension for Chrome Browser and Firefox Browser (including Android) which automatically logs into the QRZ.com website.
  • Q to H extension for Chrome Browser and Firefox Browser (including Android) which redirects QRZ callsign lookups to HamQTH.
  • NetLogger Elf Java NetLogger helper application to generate QSL cards and create nicer ADIF file to import into 3rd party loggers.
